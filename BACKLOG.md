# Бэклог — Академия Барберов

Документ описывает функционал, который входит в MVP по ТЗ, но ещё **не реализован**, а также задачи следующих этапов.

---

## 🔴 MVP — не реализовано (приоритет: высокий)

Функционал, который входит в ТЗ MVP, но отсутствует в текущей версии.

### 1. Панель преподавателя (Flutter UI)

Бэкенд-API готов (`/teaching/*`), интерфейс не создан.

| Экран | Что нужно |
|-------|-----------|
| Мои ученики | Список учеников по каждому курсу с фото и статусом |
| Расписание | Календарь/список занятий преподавателя |
| Посещаемость | Отметить присутствие/отсутствие на каждом занятии |
| Оценки | Выставить оценку (1–5) с комментарием по итогам курса |
| Материалы | Добавить PDF-ссылку или ссылку на видео к своему курсу |

---

### 2. Личный кабинет ученика — неполный

Текущее состояние: список записей + статус оплаты.

| Что отсутствует | Описание |
|-----------------|----------|
| Расписание ближайших занятий | Сгруппированный список `Sessions` из подтверждённых записей |
| История пройденных курсов | Записи со статусом `confirmed` и завершёнными занятиями |
| Учебные материалы | Просмотр PDF и видео-ссылок по записанным курсам |
| Оценка и посещаемость | Просмотр своих оценок и отметок посещаемости |

---

### 3. Уведомления — только заглушки

Инфраструктура (BullMQ, очередь) готова, методы отправки — `console.log`.

| Канал | Статус | Что нужно |
|-------|--------|-----------|
| Push (FCM) | ❌ Заглушка | Интегрировать Firebase Admin SDK на бэкенде, `firebase_messaging` в Flutter |
| Email (SMTP) | ❌ Заглушка | Подключить nodemailer / транзакционный провайдер (Sendgrid, Mailgun) |
| Telegram | ❌ Заглушка | Реализовать вызов Telegram Bot API (`sendMessage`) |
| Firebase в Flutter | ❌ Не настроен | `google-services.json` / `GoogleService-Info.plist`, инициализация `firebase_core` |

---

### 4. Фото курсов

| Что отсутствует | Описание |
|-----------------|----------|
| Загрузка фото | Endpoint `PATCH /courses/:id/photo` есть, но MinIO не настроен для реальной загрузки |
| Flutter UI загрузки | Кнопка выбора фото в форме создания/редактирования курса |

---

### 5. Редактирование курса (Flutter UI)

API `PATCH /courses/:id` готово. Нужен экран редактирования — аналог экрана создания, но с предзаполненными полями.

---

### 6. Редактирование расписания (занятий)

| Что отсутствует | Описание |
|-----------------|----------|
| Редактирование занятия | `PATCH /courses/:id/sessions/:sessionId` — нет эндпоинта и UI |
| Удаление занятия через UI | Endpoint `DELETE` есть, кнопки в admin-панели нет |

---

### 7. Деактивация пользователей (Flutter UI)

API `DELETE /users/:id` (деактивация) готово. В списке пользователей нет кнопки деактивации.

---

### 8. Архивирование курса (Flutter UI)

API `PATCH /courses/:id/archive` готово. Кнопки в admin-панели нет.

---

### 9. Поиск и фильтрация в admin-панели

| Что отсутствует |
|-----------------|
| Фильтр записей по курсу / статусу / дате |
| Поиск пользователя по имени / email |
| Фильтр курсов по статусу / уровню |

---

### 10. Смена пароля

Нет ни API-эндпоинта (`PATCH /users/me/password`), ни UI.

## 🔵 Следующие этапы (за пределами MVP)

Отложено по ТЗ — реализовывать после завершения MVP.

| Функционал | Описание |
|------------|----------|
| **Онлайн-оплата** | Карты / СБП / рассрочка. Нужен выбор провайдера (ЮKassa, Stripe и др.) |
| **Сертификаты** | Генерация PDF-сертификата по завершении курса |
| **Аналитика** | Заполняемость групп, выручка, популярность курсов, должники |
| **Мультифилиальность** | Несколько городов/филиалов — `Branch` сущность, `branch_id` в курсах |
| **WhatsApp уведомления** | Новая реализация `NotificationChannel` |
| **Рейтинг курсов** | Отзывы и оценки от учеников |
| **Промокоды / скидки** | Применение скидок при записи |
| **Экспорт данных** | Выгрузка учеников, записей, оплат в Excel/CSV |
| **Веб-администрирование** | Отдельный веб-интерфейс для более удобного управления |
