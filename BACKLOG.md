## 🔴 MVP — не реализовано (высокий приоритет)

### 1. Панель преподавателя (Flutter UI)

Бэкенд-API готов (`/teaching/*`). Нужно создать экраны:

| Экран | Описание |
|-------|----------|
| **Мои ученики** | Список учеников по курсам, имя и email |
| **Расписание** | Список занятий преподавателя по датам |
| **Посещаемость** | Отметить присутствие на каждом занятии |
| **Оценки** | Выставить оценку (1–5) с комментарием |
| **Материалы** | Добавить PDF-ссылку или видео к курсу |

API: `GET /teaching/my-students` · `GET /teaching/my-courses` · `POST /teaching/attendance` · `POST /teaching/grades` · `POST /courses/:id/materials`

---

### 2. Личный кабинет ученика — неполный

Текущее состояние: только список записей + статус оплаты.

| Что отсутствует | API | Описание |
|-----------------|-----|----------|
| Расписание ближайших занятий | `GET /courses/:id/sessions` | Занятия из подтверждённых записей |
| История пройденных курсов | `GET /bookings/my` | Завершённые записи |
| Учебные материалы | `GET /courses/:id/materials` | PDF и видео по курсам ученика |
| Оценка и посещаемость | `GET /teaching/grades/booking/:id` | Результаты обучения |

### 3. Уведомления — только заглушки

Очередь (BullMQ + Redis) готова, фактическая отправка не реализована.

| Канал | Статус | Что нужно |
|-------|--------|-----------|
| **Push (FCM)** | ❌ Заглушка | Firebase Admin SDK на бэкенде + `firebase_messaging` в Flutter + `google-services.json` |
| **Email (SMTP)** | ❌ Заглушка | Настроить nodemailer + реальные SMTP-реквизиты |
| **Telegram Bot** | ❌ Заглушка | Создать бота, вызывать `POST https://api.telegram.org/bot{token}/sendMessage` |
| **Firebase в Flutter** | ❌ | Инициализация `firebase_core`, обработка токенов push |

Файл очереди: `backend/src/notifications/notifications.processor.ts` — там `// TODO` для каждого канала.

## Технический долг

| Задача | Приоритет | Описание |
|--------|-----------|----------|
| TypeORM миграции вместо `synchronize: true` | 🔴 | В production `synchronize` опасен. Нужно `npm run migration:generate` |
| Rate limiting на auth-эндпоинтах | 🔴 | `@nestjs/throttler` на `/auth/login` и `/auth/register` |
| Пагинация списков | 🟡 | Курсы, записи, пользователи — при росте данных без пагинации будет медленно |
| e2e-тесты бэкенда | 🟡 | Покрыть основные флоу: регистрация, запись, оплата |
| Валидация UUID в параметрах | 🟡 | `ParseUUIDPipe` на Param(':id') везде |
| 152-ФЗ (персональные данные) | 🔴 prod | Соглашение об обработке ПДн, хранение в РФ — перед production |
| HTTPS на локальном Flutter dev | 🟢 | `flutter_secure_storage` требует HTTPS на Android 9+ |

## Известные ограничения текущей версии

- **Бэкенд** работает на временном Cloudflare tunnel — URL меняется при перезапуске. Для постоянной работы нужно задеплоить на Fly.io или Render.com (конфиги готовы: `fly.toml`, `render.yaml`)
- **APK** собирается с захардкоженным URL бэкенда — при смене адреса нужна пересборка. Решение: `dart-define API_URL=...` при сборке
- **S3/MinIO** не настроен — фото курсов не загружаются
- **Уведомления** выводятся только в консоль бэкенда
