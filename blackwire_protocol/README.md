# BLACKWIRE PROTOCOL

Тактическая X-COM-подобная игра в киберпанк-сеттинге. Тайное подразделение
**Reclaim** противостоит трём корпорациям — **Titan Dynamics** (ЧВК),
**Nexus Robotics** (боевые дроиды) и **Chimera Labs** (мутанты) — сдерживая
рост глобального хаоса в городе.

## Стек

- **Flutter** + **Flame** (2D top-down тактический движок, векторная
  отрисовка кодом без спрайт-шитов) — кроссплатформенность: iOS, Android,
  macOS, Windows, Linux, Web.
- **Riverpod** (`flutter_riverpod`) для состояния стратегического слоя.
- Локальное сохранение в JSON через `path_provider` (без сервера —
  игра полностью одиночная).

## Игровые механики (MVP)

### Тактический бой
- Пошаговый бой: движение + одно действие за ход (упрощённая система, как в
  XCOM 2012).
- Укрытия (крейты — половинное, стены — полное) и line-of-sight/fog of war.
- Permadeath: погибший боец безвозвратно теряется.
- Процедурная генерация карт (гарантированно связный уровень).
- Тактический AI противника: выбирает уязвимую цель, при сближении ищет
  огневую позицию в укрытии, а при критическом HP отходит и разрывает
  линию огня.
- Сложность масштабирует численность, HP и меткость противников; дальность
  обнаружения совпадает с видимостью игрока, а частота fear-атак ограничена,
  чтобы избегать неконтролируемых цепочек паники.

### Стратегический слой
- **База**: Казармы, Медотсек, Разведцентр, Мастерская, Лаборатория, Ангар,
  Склад — каждое помещение прокачивается и даёт свой эффект (вместимость
  отряда, производство снаряжения, скорость исследований, число
  одновременных миссий, лимит хранения ресурсов). Медотсек ускоряет
  пассивное восстановление и позволяет оплатить интенсивную терапию.
- **Разведцентр**: победы приносят трофеи корпораций — архивы ЧВК, ядра
  памяти дроидов и биообразцы. Их анализ даёт Данные, а улучшения центра
  повышают выход ресурса.
- **Ресурсы**: Кредиты, Материалы, Данные.
- **Исследования**: открывают оружие, броню и боевые расходники. Осколочные
  гранаты бьют по площади в обход укрытий (и задевают своих), боевые
  стимуляторы дают +2 к движению и +15 к меткости на два хода.
- **Геоскейп**: реальное время (с паузой/ускорением), у каждой фракции
  растущий уровень угрозы, общий индикатор хаоса. Поражение — при
  достижении хаосом 100%.
- **Параллельные операции**: Ангар ограничивает число одновременно
  отправленных автономных отрядов. Операции идут по таймеру, блокируют
  назначенных бойцов и завершаются отчётом с наградами, ранениями или
  потерями.
- Раненые бойцы восстанавливаются в медотсеке; улучшения ускоряют лечение.

## Запуск

```bash
flutter pub get
flutter run -d chrome        # веб
flutter run -d macos         # macOS (требуется соответствующий SDK)
flutter run -d linux         # Linux desktop
flutter run                  # подключённое мобильное устройство/эмулятор
```

## Тесты

```bash
flutter analyze
flutter test
```

Юнит-тесты покрывают процедурную генерацию карт, line-of-sight,
pathfinding, боевую систему (укрытия, урон, шанс попадания), полный цикл
хода `BattleController`, а также стратегическую логику
(`GameStateNotifier`: результат миссии, апгрейды базы, исследования).
Виджет-тесты проверяют экран боя (оверлей победы/поражения, навигация).

## Структура проекта

```
lib/
  core/            константы, тема
  data/            модели домена, каталоги контента (оружие/броня/
                   исследования/регионы), сохранение
  game/            игровая логика (карта, LOS, pathfinding, бой, AI,
                   Flame-рендеринг) — не зависит от Flutter UI
  state/           Riverpod-нотифаер стратегического состояния игры
  features/        экраны (меню, база, геоскейп, ростер, исследования,
                   тактический бой)
```

## Известные ограничения MVP

- У каждой специализации есть своё сигнатурное тактическое действие
  (натиск, прицельный выстрел, подавление, полевое лечение, взлом дроида и
  развёртывание турели) — одно применение за бой.
- Исследованные гранаты и стимуляторы выдаются каждому бойцу отряда по
  одному заряду на миссию. Отдельного инвентаря и выбора снаряжения перед
  вылетом пока нет.
- Оформление боя минималистичное: векторные примитивы вместо спрайтов,
  без звука и анимаций перемещения.
