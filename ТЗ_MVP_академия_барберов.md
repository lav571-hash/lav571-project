# ТЗ: Приложение для академии барберов (MVP)

## 1. Краткое описание

Кросс-платформенное приложение для академии барберов с возможностью записи учеников на курсы и подтверждением оплаты. В MVP оплата онлайн не реализуется — подтверждение оплаты вносит администратор вручную.

## 2. Платформы

- iOS (мобильное приложение)
- Android (мобильное приложение)
- Веб-приложение (браузер)

Технологии подбираются с приоритетом на кросс-платформенность.

## 3. Язык и дизайн

- Язык интерфейса: **только русский**.
- Дизайн разрабатывается **с нуля**, в современном минималистичном стиле, уместном для барбер-индустрии.
- Готового фирменного стиля нет.

## 4. Роли пользователей

### 4.1. Ученик
- Регистрируется самостоятельно.
- Просматривает каталог курсов.
- Записывается на курсы/слоты.
- Видит статус оплаты своих записей.
- Отменяет запись самостоятельно — **только до подтверждения оплаты**.

### 4.2. Администратор
- Аккаунт заводится администратором (не саморегистрация).
- Создаёт слоты под запись.
- Вносит и редактирует расписание.
- Подтверждает оплату учеников вручную.
- Отменяет записи после подтверждения оплаты.
- Заводит аккаунты администраторов и преподавателей.
- Настраивает параметры (в т.ч. срок автоснятия брони).

### 4.3. Преподаватель
- Аккаунт заводится администратором.
- Видит список своих учеников.
- Видит своё расписание.
- Отмечает посещаемость.
- Ставит оценки.
- Загружает учебные материалы (PDF и ссылки на видео).

## 5. Аутентификация

- Вход для всех ролей: **email + пароль**.
- Ученики регистрируются сами.
- Аккаунты администраторов и преподавателей создаёт администратор.

## 6. Курсы

Поддерживаются разные форматы курсов:
- Разовые занятия.
- Многодневные программы (несколько занятий).
- Курсы для разных уровней (начинающие, продвинутые и т.д.).

Каждый курс имеет **ограничение по количеству мест** в группе.

### 6.1. Информация о курсе (отображается ученику перед записью)
- Название
- Описание
- Уровень
- Преподаватель
- Даты и время занятий
- Длительность
- Цена
- Количество свободных мест
- Фото
- Программа курса

## 7. Запись и оплата (MVP — без онлайн-оплаты)

Сценарий записи:
1. Ученик записывается на слот/курс.
2. Место бронируется со статусом **«ожидает оплаты»**.
3. Ученик оплачивает вне приложения (наличные/перевод).
4. Администратор отмечает **«оплачено»**, место подтверждается (статус **«подтверждено»**).

### 7.1. Автоснятие брони
- Если оплата не подтверждена в течение заданного срока, бронь снимается автоматически, место освобождается.
- Срок автоснятия — **настраиваемый параметр** (задаёт администратор).

### 7.2. Отмена записи
- Ученик может отменить запись **сам только до подтверждения оплаты**.
- После подтверждения оплаты отмену выполняет **только администратор**.
- Возврат средств оформляется вручную вне приложения.

## 8. Уведомления

Каналы: **push, мессенджеры, email**.

События для уведомлений:
- Подтверждение записи.
- Напоминание об оплате.
- Напоминание о начале занятия.
- Отмена брони.

## 9. Личный кабинет ученика

- Текущие записи со статусом («ожидает оплаты» / «подтверждено»).
- История пройденных курсов.
- Расписание ближайших занятий.
- Учебные материалы (PDF и ссылки на видео).

## 10. Границы MVP

### Входит в MVP
- Регистрация учеников (email + пароль).
- Создание аккаунтов администраторов и преподавателей администратором.
- Каталог курсов (разовые/многодневные, разные уровни, ограничение мест).
- Запись с бронью и ручным подтверждением оплаты.
- Настраиваемый срок автоснятия брони.
- Отмена записи (учеником до оплаты, администратором после).
- Уведомления (push, мессенджеры, email).
- Личный кабинет ученика.
- Отметка посещаемости и оценки (преподаватель).
- Учебные материалы (PDF и ссылки на видео).

### Отложено на следующие этапы
- Онлайн-оплата (карты, СБП, рассрочка и т.п.).
- Несколько городов/филиалов (мультифилиальность).
- Выдача сертификатов.
- Аналитика и отчёты (заполняемость, выручка, должники, популярность курсов).

## 11. Открытые вопросы для следующего этапа

- Выбор платёжного провайдера для онлайн-оплаты.
- Конкретные мессенджеры для уведомлений (Telegram / WhatsApp / др.).
- Требования к безопасности и хранению персональных данных.
- Возможные интеграции (CRM, бухгалтерия и т.п.).
- Требования к производительности и нагрузке.
